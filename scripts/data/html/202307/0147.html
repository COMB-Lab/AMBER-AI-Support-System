Is there a reason specifically you want TIP5P? If your goal is simply to
have a water model that is better than TIP3P, would OPC work for you? This
is a 5-pt water model that does better than TIP5P in many respects. I'm
not sure about the density specifically but you can check out papers
from Onufriev's group on this. And lots of people use OPC in AMBER so the
parameter files are all set up for you.

> Hi,
>
> If you check by saving a TIP5P water (as pdb), you will see there is a
> triangulated portion consisting of OW and HW atoms (like in the TIP3P
> model). But, if you look at the frcmod.tip5p file, there is no mention of
> OW-HW and HW-HW bond parameters. These parameters are required for the
> successful building of your model system.
>
> If you create a frcmod file (in your working directory) by copying the
> bond parameters from the frcmod.tip3p file and supply its path in the tleap
> file before saving the topology and restart, the system can be built
> successfully. However, I don't know if it is a safe thing to do by just
> copying the other water parameters.
