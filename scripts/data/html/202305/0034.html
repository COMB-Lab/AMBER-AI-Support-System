Assuming "veldcd" is just a DCD file with velocity information, you
should be able to just output to a DCD file, something like:

trajin mytraj.nc mdvel velocities.mdvel
trajout mytraj.dcd

If your velocities are in the NetCDF coordinate file already you won't
need the mdvel keyword.

-Dan
