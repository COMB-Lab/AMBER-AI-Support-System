Hi Dulal,

the difference between outtraj and trajout is that one (trajout) waits for
all actions (like rms fitting) to be completed before writing, while
outtraj writes immediately. cpptraj commands are not (necessarily) executed
in the order they are written. This can be confusing indeed. My
understanding is that this is the order of execution in your example

1 trajin mdcrd.crd
5 trajout output.crd
2 outtraj BeforeRmsd.crd
3 rms R1 first :1-20.CA out rmsd.dat
4 outtraj AfterRmsd.crd

note how trajout is delayed to the end and therefore writes the same
coordinates as AfterRmsd.crd.
