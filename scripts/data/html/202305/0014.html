If you are running long simulations, a good practice is to break them into
chunks, so that in case there is some issue in computing, you do not lose
all data at once. Now when you need to restart your simulations from a
particular state, you do need somewhere to start from, right? The rst file
serves as that. It contains information about the last save dstate of
thesystem. Your next simulation run will continue from that state so that
there is continuity.
