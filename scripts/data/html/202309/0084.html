Hi Sourav,

you didnt tell us what steps you performed before seeing this error, so I
can only offer a guess. To use a non-standard residue in Amber it needs a
residue description and force field parameters defined, as described in
this tutorial: http://ambermd.org/tutorials/basic/tutorial4b/

Doing the same steps for a Se-containing compound would not be different in
principle, though you may run into issues in e.g. QM charge fitting if the
element is not supported in your QM program of choice.

If you have done all these steps already, then the error you see is likely
due to atom/residue name mismatches between your input pdb and parameter
files.

Kind Regards,

Thomas
