It looks to me like you built Amber using python 3.8, since your files
are all in places like ...amber18/lib/python3.8/site-packages/.... To use
these files, you should use the version of python that Amber was built with.

If you need python3.9, then re-configure AmberTools with python 3.9. While
you are at it, download AmberTools20 to take advantage of two years worth of
improvements and bug fixes.
