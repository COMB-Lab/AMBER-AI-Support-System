Hi,

VMD detects file format by file name extension, and I don't think
'.rst' is recognized as "Amber restart" by VMD. Try changing the file
name extensions to '.rst7' and see if that helps.

Alternatively, try writing the files in the netcdf restart file format
(.ncrst extension).

-Dan
