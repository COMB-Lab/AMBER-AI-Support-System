     For details:
     Â Â 1. I have updated to the newest version including update.8 and
     update.12 for Amber20 and Ambertool20, respectively.
     Â Â 2. I used the legacy way to install. Because the error of âunsupported

     CUDA 11.1 + Nvidia 3080 calculation failed, with above error message.

     Solution:
     The modification in step2 is not enough. Because the gencode is only
     support to sm75.
     While The 3080 card requires sm86.
     So, I added two lines, highlighted as red as below.
     Original:
     Â Â Â if [ "$cudaversion" = "11.0"]; then
     Â Â Â Â Â Â # Implement the standard, not warp synchronous, compilation

     Â Â Â Â Â Â sm70flags='-gencode arch=compute_70,code=sm_70'
     Â Â Â Â Â Â echo "CUDA Version $cudaversion detected"
     Â Â Â Â Â Â echo "Configuring for SM5.0, SM5.2, SM5.3, SM6.0, SM6.1,
     SM7.0, SM7.5 and SM8.0"
     Â Â Â Â Â Â nvccflags="$sm50flags $sm52flags $sm53flags $sm60flags
     $sm61flags $sm70flags $sm75flags $sm80flags $sm86flags
     -Wno-deprecated-declarations"
     changed to:
     Â Â Â if [ "$cudaversion" = "11.0" -o "$cudaversion" = "11.1" ]; then
     Â Â Â Â Â Â # Implement the standard, not warp synchronous, compilation
     Â Â Â Â Â Â sm86flags='-gencode arch=compute_86,code=sm_86'
     Â Â Â Â Â Â sm80flags='-gencode arch=compute_80,code=sm_80'
     Â Â Â Â Â Â sm75flags='-gencode arch=compute_75,code=sm_75'
     Â Â Â Â Â Â sm70flags='-gencode arch=compute_70,code=sm_70'
     Â Â Â Â Â Â echo "CUDA Version $cudaversion detected"
     Â Â Â Â Â Â echo "Configuring for SM5.0, SM5.2, SM5.3, SM6.0, SM6.1,
     SM7.0, SM7.5 and SM8.0"
     Â Â Â Â Â Â nvccflags="$sm50flags $sm52flags $sm53flags $sm60flags
