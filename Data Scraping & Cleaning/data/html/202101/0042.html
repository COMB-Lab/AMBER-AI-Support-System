Looks like your AMBERHOME environment variable is not set. Note that you
must cd to /usr/local/amber20 and type "source amber.sh" after running "make
install" but before running the test suite. Consider putting this into your
startup scripts (e.g. .bashrc) so that it will be done at each login.
