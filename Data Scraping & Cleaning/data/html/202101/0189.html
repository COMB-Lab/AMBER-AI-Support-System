don't use the PDB file for checking bonds. either use parmed to list bonds,
or visually in VMD load the prmtop first, then the coordinates. That way it
uses the prmtop for bond information. If you load the pdb then VMD will use
distances to create its own bond list.

When leap says "there is a bond of... between... " it should list which
atoms, did you check those? Hard to say more without seeing the actual
message you are talking about.
