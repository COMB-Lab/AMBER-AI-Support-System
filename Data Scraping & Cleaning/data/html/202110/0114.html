On Thu, Oct 14, 2021, Ravi Abrol wrote:
>
>I ran the test.mmpbsa and it was successful. It seems to delete the output
>files after comparing with reference output.
>Is there a flag to not delete them, so that I can see all the files my test
>generated?

You have to go into the test scripts themselves, and add the "-k" flag to
the invocations of dacdif. This will keep all your files.

But if the tests pass, the files that were deleted will be identical to the
ones with a ".save" or ".check" extension, except for lines starting with
"|".
