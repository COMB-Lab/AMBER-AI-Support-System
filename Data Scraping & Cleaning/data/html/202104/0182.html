update.13 makes changes to two files, preparing them for use with CUDA SDK
version 11.x. First, if you are not using version 11.1 or 11.2 for CUDA,
you should be able to ignore this message.

You can look in the cmake and AmberTools/src folders for ".rej" files that
will give more information about what happened. It looks like you have
earlier changes in those files that prevent the patch from applying. A
second alternative is to look at the update.13 file (it's available on the
web site) and make the changes "by hand": if you are using CMake there is
only a single line that needs changing.

A third alternative, if you haven't made other changes to the code, is to
re-install things from the original tar files. This seems very likely to
work, since everyone who downloads AmberTools goes through the update step,
and no else has reported a problem.

....good luck....dac
