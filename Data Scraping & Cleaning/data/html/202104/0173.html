You have a very small box size...very near the limit for Amber.

You need to reduce your cutoff for such a small cell. I'm guessing(?) that you set cut=9.287 in response to earlier messages like this. But with constant pressure, the cell size will decrease, and with it, the largest value of cut that you can use.

If this is "just" a student project, using the default cut of 8.0 should be fine for teaching. If you need to explore bigger cutoffs, you'll need to construct a bigger box.
