cpptraj and pytraj are a standard part of AmberTools21. If you have any
problems building and installing these, please report details to the mailing
list.

Note that update.2 can be important to get pytraj working correctly on some
machines.. Updates are applied by default in the usual build procedure,
i.e. applied unless you explicitly turn them off.
