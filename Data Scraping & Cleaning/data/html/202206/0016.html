Hi,

I just added this feature to the GitHub (https://github.com/Amber-MD/cpptraj) version of cpptraj (version 6.8.1) via the new keyword 'toxyz <x>,<y>,<z>'. So for example to calculate the RDF for water after recentering the system on the origin (0, 0, 0):

parm ../tz2.truncoct.parm7
trajin ../tz2.truncoct.nc
autoimage origin
radial out wat.origin.agr 0.25 15.0 :WAT.O toxyz 0,0,0

Hope this helps,

-Dan
