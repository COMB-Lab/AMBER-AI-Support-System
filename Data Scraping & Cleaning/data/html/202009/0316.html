Hi Chetna,
Sorry for the late response. At least in packmol-memgen there is no model
for lysyl-phosphatidylglycerol. If you want to add them, you would have to
parametrize the headgroup following the Lipid11/14 rationale and modify the
parameter file included within the script. Send me a message if you are
interested in that.
For cardiolipins, if you have AmberTools20, you can add them directly from
the script; please check the manual entry about this. These lipids have not
been published at the moment, so used them with care.
Cheers,
