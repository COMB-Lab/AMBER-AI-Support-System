HI Swapnil,

I have installed AmberTools20 on Ubuntu 20.04 LTS natively (standalone OS) as well as on WSL in Win 10 64-bit without fail.

I did encounter an issue on Ubuntu 20.04 LTS recently where installation failed around 40%. However, after a fresh install of Ubuntu, it worked fine. The only difference in the two Ubuntu installations was that in the previous install I installed CUDA Toolkit 11.0 and then installed AmberTools. When I reversed the order on the fresh Ubuntu install (AmberTools installed first and then CUDA Toolkit 11.0), AmberTools worked fine. This issue may just be an incidental occurrence unrelated to CUDA because I did not install the CUDA versions in both the installs. Maybe a fresh Ubuntu install helps you too!

I did encounter one error while installing AmberTools more than once. The error was something like �cmake could not find OpenSSL�. This was resolved by adding the requisite package using the following command in Ubuntu Terminal:

sudo apt-get install libssl-dev


It will be helpful if you could post the error(s) for someone on the list to help you.

Regards,
Raman
