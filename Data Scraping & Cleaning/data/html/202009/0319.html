I am sure it is possible, though as far as I found after a quick search, there is no simple way to change the font of applications being forwarded. If the application is gtk based, it seems possible with a little work though I don’t know if xleap is gtk based or native x.

Changing the font of the xterm is simple though changing fonts in applications being forwarded (server-client) seems like a bigger problem. There should likely be some configuration for xleap somewhere defining the font to use.

In any case, the fonts used by XQuartz (what I am using) are not very pretty to begin with.
