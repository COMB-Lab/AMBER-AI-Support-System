Something like this input should work.

parm myparm.parm7
trajin mytraj.nc
# Strip all but CA atoms, write CA-only topology
strip !.CA parmout CA.parm7
# Write CA-only trajectory
trajout CA.nc

Hope this helps,

-Dan
