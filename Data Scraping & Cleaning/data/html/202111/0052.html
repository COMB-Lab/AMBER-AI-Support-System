Hi,
Try with this .trajin script to extract out your frames.
trajin prod_run.nc " (.nc file from production run)"
autoimage
center :a -b mass origin "[a(first residue number)-b(last residue number), # residue number in your file]"
image origin center
trajout prod_run_frames_COM.pdb ( output file name)
