I see similar, failed, behavior with "Edit Selected Atoms" on my Mac. This
may be an End of Life signal for xleap, at least for the Edit Atoms table.
Xleap was written around 1990, and uses truly ancient X-window widgets.
I don't know of anyone with the skill set to modify the source code here.

One thing I can try (or you can to, perhaps) is to replace the XQuartz X11
server with an alternate server, say from Macports. That might be more
compatible with old X-window code.

FWIW, everything seems to work fine for me on Ubuntu 21.04. Are you using
WSL on Windows? If so, are you using xorg-dev?
