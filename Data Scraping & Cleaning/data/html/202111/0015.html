Hi,

I still see ntr= 1 in both your input files. If you wan to conduct unrestrained heating you should have ntr = 0 instead.

Also, if you want to gradually decrease the wt of restraint, you need to decrease restraint_wt from its current value. See for 5 kcal/mol this parameter should be restraint_wt = 5.0. Similarly for the following subsequent heating, keep decreasing this restraint_wt value until zero.

Hope this helps,
Mohamed
