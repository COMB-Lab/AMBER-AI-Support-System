Several things to try for debugging:

1. Do the mmpbsa_py test cases work in parallel? That will help see if the
problem might be with your inputs.

2. Can you do a short (many fewer frames) analysis with the serial
version? This also can help to narrow down the problem.

3. Have you examined all the output files to look for error messages?
When problems happen with mmpbsa, the actual error messages are often
inside the individual output files.
