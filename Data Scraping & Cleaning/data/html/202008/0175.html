Hi,

For CUDA 7.5 you will need driver version >= 352.31.
https://docs.nvidia.com/deploy/cuda-compatibility/index.html

Ensure you are running at least that version. Then check you can run a
CUDA program by e.g. compiling and running the deviceQueryDrv SDK
sample.

-Dan
