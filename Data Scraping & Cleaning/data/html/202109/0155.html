You should not need to be root to install Amber, and we recommend against
doing so.

Detailed installation instructions are in Chapter 2 of the Reference Manual,
and CentOS details are here:

     https://ambermd.org/InstCentOS.php

You don't say whether you ever tried to install as an ordinary user, and (if
so) what happened. Be sure that you are installing to a folder where you
have write permissions. But if you succeeded in installing as root, the
procedure is no different for non-root.

...good luck...dac
