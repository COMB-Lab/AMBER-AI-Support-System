Hi,

You could try:

parm parm1
trajin traj1 parmindex 0
esander E1 …
run
clear trajin
parm parm2
trajin traj2 parmindex 1
esander E2 …
run

You could also load the trajectories as COORDS data sets with ‘loadcrd’ and
use ‘crdaction’.

Hope this helps,

-Dan
