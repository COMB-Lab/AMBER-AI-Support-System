Hi,

First, if the AMBERHOME directory has been moved, check that AMBERHOME
has been updated to the new location in the $AMBERHOME/amber.sh
script.

Second, ensure that the permissions on the shared library files allow
you to access them (you need r+x I believe). You can check this with
'ls -l <library file>' and 'file <library file>'.

Hope this helps,

-Dan
