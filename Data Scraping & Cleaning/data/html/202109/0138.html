Somehow, you need to debug this really carefully. Look at line 124 in the
original files (before running update_amber). Is it the line listed above?

Then, run update_amber --update, and pay careful attention to the output,
looking for any evidence that the updating process failed for update.1.

Look at line 124 *after* the update step? Has it changed? Is there a file
ending in ".rej" in that directory?

Possible problems: you don't have a proper internet connection to get the
updates; the "patch" program on your machine is missing, or not working
somehow; something is wrong with permissions that prevents the patches from
actually being carried out; ....(??)
