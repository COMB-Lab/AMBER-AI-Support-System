On Sat, May 01, 2021, Rudy Richardson wrote:

>What if you are updating from AMBERTools20 that was installed with the
>parallel option and you wish to install ReaxFF?

Note that the upgrade (not update) to AmberTools21 requires one to do fresh
run of cmake and make install in any event. So just set the options you
want in the run_cmake script.

It is currently true that to get both reaxff and parallel versions of other
codes, one needs to run cmake twice. The reaxff stuff is very new, and
there may be other rough edges as well. Please report any problems that you
find.
