Hi,

As pointed out to me by Dr. Christina Bergonzo, G-U base pairing can
be very transient, so you may want to try adding the 'allframes'
keyword to the 'nastruct' command so that cpptraj determines base
pairing each frame instead of based on the first frame.

-Dan
