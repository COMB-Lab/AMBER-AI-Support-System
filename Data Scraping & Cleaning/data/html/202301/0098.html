Hi Broto,

Be sure to apply the latest updates before trying to compile. That will add support for CUDA 11.8. (Note the version reported by nvidia-smi is the latest version of CUDA that the driver will support. nvcc -v gives you the version of the CUDA compiler you are using).

cd amber22_src/
./update_amber --update

All the best
Ross
