Hi,

Some quick notes- someone else might be able to add more details-


> addIons: 1st Ion & target unit have charges of the same sign:
> unit charge = -2e-06; ion1 charge = -1;
> can't neutralize.
>

If I remember correctly, the non-zero charge is an artifact from how RESP
tries to fit the charges- you end up with some trailing decimals since it
has to round to 6 decimal places, so you either ignore it or manually
fiddle with it so it's 0

When I look the .pdb created by the leap.in, it doesn0t look like the KCX
> residue is connected to the protein since we can see the dotted line where
> a residue should be in a cartoon vizualization.
>

I think that (someone else can chime in if it's true or not) has to do with
starting coordinates for the molecule- you can 'cheat' around it by having
an atom that's part of your KCX residue attached where you want it to
start, and then leap will rebuild off of that. Obviously, if you're putting
it on manually, you might want to do some extensive
minimization/equilibration for a bit

Should I have written in leap.in file for the bond to be created?
> bond a./number_of_residue1/.C a./number_of_residue2/.N
> bond a./number_of_residue2/.N a./number_of_residue3/.C
>

I don't think you have to- it's been a while since I've messed with
antechamber prep files, but if you have the initial model you used for the
input, you should be able to edit the prepin to add in the bon manually.

Best,
Kenneth
