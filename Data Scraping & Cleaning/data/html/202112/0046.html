Same procedures are also applicable to convert .mdcrd into .dcd format.

On Dec 3, 2021 7:25 AM, Mohamed Aboelnga <mohamed.aboelnga.uwaterloo.ca> wrote:
Hello,

You need to convert the .crd file into .dcd using cpptraj to be able to open the trajectory using VMD.

Here is how it could be done in cpptraj
parm filename.prmtop
trajin filename.crd
trajout filename.dcd

Hope this help.

Mohamed
