> Hi all,
>
> Thank you all for your suggestions. My protocol is finally working well.
> I don't need any restraints. The key was to use NPT ensemble in case of
> unrestrainted simulation. It is pretty obvious that GPU code does not
> work properly with NPT ensemble. I don't think this limitation is widely
> known within Amber comunity, because It took me 5 days of reading
> articles and googling to figure it out. But in the end, its not a
> disaster, because NVT ensemble has better performance. For my system 75
> ns/day instead of 50 ns/day.
>
> In order to use NVT, density needs to be equilibriated before. For that,
> you can use NPT with restrained ligands with GPU code or CPU code
> without restraints. 100 ps is usually enough, so CPU code is not a problem.
>
