There is no box information there: box info would have 6 numbers on the
final line (3 box dimensions and 3 angles, typically 90.0 or 109.).

Did you set up the prmtop file with periodic boundary conditions? Did
you set ntb=1 when you ran the minimizations?

Run parmed on your prmtop file, and issue the "summary" command: does it
list a system volume? If not, the prmtop itself is not set up for
periodic simulations. If yet, then something is wrong with your restart
file.
