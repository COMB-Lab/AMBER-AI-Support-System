>I get the following error trying to make amber on centos 7

>environment. Requires 'C++ include files' setting gathered from 'g++'
>error: command 'icc' failed with exit status 1"

Somehow, your intel compiler setting are odd. For the large majority of
users, there is little benefit in using Intel compilers. I'd suggest just
installing using the GNU compilers.

If you want to explore the Intel issue more, add --skip-python to the
configure flags you use, ask for the Intel compilers, and see if other
problems pop up.
