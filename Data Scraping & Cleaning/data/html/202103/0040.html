On Fri, Mar 05, 2021, Pinky Mazumder wrote:
>
>Is it possible to install AMBERTools20 with Amber18.tar.bz2?

Yes, but change "with" to "alongside". Untar the AmberTools20 file, which
goes into a folder called amber20_src. Follow the instructions, including
sourceing the amber.sh file, which will set your AMBERHOME variable to point
to AmberTools20.

When you want to run pmemd (the only program that you won't have, run that
from the amber18/bin directory. pmemd doesn't make use of the AMBERHOME
variable.

...hope this helps...dac
