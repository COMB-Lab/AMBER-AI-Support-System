>getting the following error:

This message says nothing more than "something went wrong". Study the mdout
file for hints. See if you can run a short CPU simulation, especially if
this error happens near the beginning of a run. Be sure you have minimized
your structure before start md with GPU.

Above are all just guesses, based on things that commonly go wrong. There
are, in fact, almost an uncountable number of ways a simulation can fail, so
you have some detective work to do here.
