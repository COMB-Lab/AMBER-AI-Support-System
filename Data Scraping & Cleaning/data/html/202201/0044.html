The file is not corrupted. It is almost certainly a NetCDF restart
file (the 'CDF' at the beginning gives it away), which has been the
default format for restart files for a while now. You can check this
yourself by using the linux 'file' command, by using 'ncdump -h', by
reading it into cpptraj etc.. Adjust the ntxo parameter if for some
reason you want to use ASCII-formatted restarts instead. Hope this
helps,

-Dan
