I think ptraj can fix this for you, probably a lot of other tools as well, including VMD and Chimera with GUIs.

for ptraj I think making an input file similar to this.

    parm [prmtop-file]
    trajin [mdcrd-file] first last step
    trajout [output file rst | ncrst | pdb | … ]

Should get the job done. Just replace the “first” with the frame you want, “last” with the same frame and I suppose you can skip “step” or set it to 1, which I suspect is the default. There is probably easier ways to do this as well though this was the first that came to mind using the tools included in amber.
