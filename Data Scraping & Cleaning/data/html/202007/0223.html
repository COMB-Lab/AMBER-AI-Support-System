Hi,

It's not clear to me exactly what you want to do. If you want to
visualize how coordinates change along a certain eigenvector you can
use the 'modes trajout' analysis command to create a
pseudo-trajectory. If you want to extract frames that correspond to a
particular projection value, you can first use the 'projection' action
command to calculate the projection along certain eigenvectors, then
the 'filter' action to only allow frames that match certain projection
values to be written by a subsequent 'trajout' statement.

Let me know if you have more questions. Good luck!

-Dan
