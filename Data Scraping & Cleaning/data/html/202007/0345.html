> In addtion,I got more than 500 rst file when I saved the rst file by the following script, how to only save the rst file of the last frame from the mdcrd file?

This is because without any other arguments, the 'trajin' command
reads the entire trajectory. If you just want the last frame use
"trajin <file> lastframe". See the manual for full details.

-Dan
