The GPU should be fine: you can see RTX5000 benchmarks on our web site.

Amber GPU runs work almost entirely on the GPU, so they don't benefit from
having a high-end, multicore CPU. And they certainly don't need anything like
128 Gb of memory.

If you need lots of memory and a powerful CPU for other jobs, fine. But if
you are buying a machine primarily to run Amber, you would save money by
looking at less powerful CPU chips, and much less memory.
