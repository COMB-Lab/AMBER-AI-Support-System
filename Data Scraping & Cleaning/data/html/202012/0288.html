I don't understand what you mean. The slurm message says that it was killed
due to time limit. I'm not sure how it could run longer unless the limit
were changed.
It's possible that something is wrong in the minimization and it is no
longer proceeding, but you would need to look at your output file to know
that. I suggest checking occasionally during minimization to see if it is
writing more data.
