Hi
Don't forget to source amber.sh before you try to run parmed.
Try this
source $AMBERHOME/amber.sh
or
add these lines in your .bashrc file
#AMBER18
export AMBERHOME=</path_to_amber>/amber18
source $AMBERHOME/amber.sh
