Hi,

The 'time' argument can be used pretty much anywhere there is an 'out
<filename' to multiply the X axis values by a factor. So for example,
if your frames correspond to ps but you want nc, use e.g. 'out
myfile.dat time 0.001'.

Hope this helps,

-Dan
