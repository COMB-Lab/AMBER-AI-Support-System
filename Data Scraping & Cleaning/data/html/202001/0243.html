>How periodic boundary conditions works with different box types in amber18.

I think you will need to ask a more specific question. There is really
only one "type" of box in Amber: a triclinic unit cell repeated via
translations. There are a few places where a separate calculation is
done for rectangular or "truncated ocataheral" boxes, but those are just
done for (rather minor) gains in efficiency.
