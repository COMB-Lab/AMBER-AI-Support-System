Asunto: [AMBER] Custom language module(s) for AMBER file types for common text editors?

Dear AMBER Users:

I’m looking for some custom language module(s) for the files used in the AMBER suite for use in Notepad++ <https://notepad-plus-plus.org/> and BBedit <http://www.barebones.com/>, and If I’m very lucky vi <https://en.wikipedia.org/wiki/Vi> inside of bash.

Notepad++ and BBedit natively support colouring for common languages like HTML, bash scripts, markdown, etc… However, I have been unable to find a language module file(s) for the AMBER files <http://ambermd.org/FileFormats.php>. Having these custom color files would greatly increase the readability of AMBER files day-to-day. Currently they are just regular text, while my bash, perl and python scripts are very colourful and easy to read at a glance. BBedit supports “codeless language modules” https://www.barebones.com/support/develop/clm.html�� <https://www.barebones.com/support/develop/clm.html> Notepad++ supports “User defined Languages” https://npp-user-manual.org/docs/user-defined-language-system/ <https://npp-user-manual.org/docs/user-defined-language-system/>

If such a module(s) exist for the text editors above can one point me in the right direction to download them? My google-fu has been unable to locate any such files. If modules do not exist where can I submit this as a ‘feature request’ for future development?
