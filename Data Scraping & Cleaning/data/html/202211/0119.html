the versions you look for are out of use and maintenance.

It is recommended to use the up-to-date versions because many fixes and
extensions have been made by the developers over the years. Please visit
the Amber website to register and download AmberTools22 for free. Note,
that the optimized main MD program in Amber requires (and has always
required) a license, which includes a fee; it is not free.

However, you might want to contact the Amber developers directly to
explain your legitimate interest in obtaining the old program versions.
